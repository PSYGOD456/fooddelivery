# Problems Encountered

## Problem 1 – Login Validation
Invalid login details needed clearer validation and user feedback.

**Solution:** Added login validation and an error message for invalid credentials.

## Problem 2 – Food Search
Search results needed to handle both matching and non-matching food names.

**Solution:** Added search handling and a not-found response for unmatched searches.

## Problem 3 – Cart Management
The cart must correctly handle adding, removing and changing quantities while keeping the total updated.

**Solution:** Updated cart logic so item quantities and the total amount are recalculated when the cart changes.

## Problem 4 – Order Validation
An order should not be created when the cart is empty.

**Solution:** Added checkout validation so an empty cart cannot be submitted.

## Problem 5 – Future Modules
Payment, delivery tracking and order history are not yet part of the current prototype.

**Plan:** Keep these modules in the backlog and implement them in later laboratory sessions.
