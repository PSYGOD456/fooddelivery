# Food Delivery App – GitHub Storyboard

## Project Title
Food Delivery App

## Objective
To develop a food delivery system where customers can browse restaurants, select food items, place orders, make payments and track deliveries.

## Storyboard / Progress

| Sl. No. | Problem / Task | Description | Status |
|---|---|---|---|
| 1 | Requirement Analysis | Identify requirements of customers, restaurants and delivery personnel | Completed |
| 2 | GitHub Repository | Create repository and add project details | Completed |
| 3 | User Registration | Allow new customers to create an account | Completed |
| 4 | User Login | Allow registered customers to log in | Completed |
| 5 | Restaurant Selection | Display available restaurants | Completed |
| 6 | Food Menu | Display food items and prices | Completed |
| 7 | Search Food | Search for required food items | In Progress |
| 8 | Cart Management | Add, remove and update food items in cart | In Progress |
| 9 | Place Order | Allow customers to place an order | Pending |
| 10 | Payment | Provide payment option for orders | Pending |
| 11 | Order Tracking | Track the status of an order | Pending |
| 12 | Order History | Display previous orders | Pending |
| 13 | Testing | Test the major functions using test cases | Pending |
| 14 | Documentation | Complete project documentation and update GitHub | Pending |

## Story Flow

Requirement Analysis → Registration → Login → Restaurant Selection → Food Menu → Search → Cart → Order → Payment → Delivery Tracking → Testing

## Software Engineering Activities

1. Requirement Analysis
2. SRS Preparation
