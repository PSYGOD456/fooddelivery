# ER Diagram – Food Delivery App

## Main Entities
- User
- Restaurant
- FoodItem
- Cart
- CartItem
- Order
- OrderItem
- Payment
- Delivery
- Review

## Key Relationships
- A User can place many Orders.
- A Restaurant can have many FoodItems.
- An Order contains one or more OrderItems.
- An Order can have a Payment record.
- An Order can have a Delivery record.
- A User can write Reviews for completed orders.
